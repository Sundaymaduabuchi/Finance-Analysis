# 📊 FinSight – Finance Analysis Dashboard

An interactive **Power BI Finance Analytics Dashboard** designed to provide actionable insights into financial transactions, customer behavior, and business performance through dynamic visualizations and data-driven storytelling.


## 📌 Project Overview

**FinSight** is a Business Intelligence solution built using **Power BI** to analyze financial transaction data and transform raw datasets into meaningful business insights.

The dashboard helps stakeholders monitor:

- Financial transaction trends
- Customer segmentation performance
- Transaction success/failure analysis
- Geographic transaction distribution
- Revenue and fee insights
- Detailed transaction-level drill-down analysis


## 🎯 Project Objectives

The primary goals of this project were to:

- Analyze financial transaction performance
- Identify customer behavior patterns
- Monitor transaction success rates
- Evaluate transaction distribution across regions
- Provide executive-level financial insights
- Build an interactive reporting solution for decision-making


## 🛠 Tools & Technologies Used

- **Power BI Desktop**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Data Modeling**
- **Interactive Dashboard Design**


## 📂 Dashboard Pages

### 1️⃣ Overview Analysis Page

Provides high-level business insights including:

- Total Amount Analysis
- Total Transactions
- Average Transaction Value
- Total Fees
- Task Performance Metrics
- Monthly Transaction Trends
- Transaction Status Distribution
- Customer Segment Analysis
- State-wise Transaction Distribution
- Gender-based Analysis
- Transaction Type Performance


### 2️⃣ Transactions Page

A detailed transaction-level report for operational analysis featuring:

- Transaction ID tracking
- Transaction date monitoring
- Customer information
- Transaction type
- Transaction status
- Customer segmentation
- Geographic transaction details
- Amount and fee analysis

## 🔄 Project Workflow

### 1. Data Collection
Imported financial transaction dataset into Power BI.

### 2. Data Cleaning & Transformation
Performed data preprocessing using Power Query:

- Removed inconsistencies
- Handled missing values
- Standardized categorical variables
- Structured date hierarchies

### 3. Data Modeling
Created relationships between tables for optimized analysis.

### 4. DAX Calculations
Developed custom measures for:

- Total Amount
- Average Transaction Value
- Total Fees
- Year-over-Year Comparison
- Dynamic Metric Calculations

### 5. Dashboard Development
Built interactive visualizations and navigation structure.

### 6. Insight Generation
Extracted business intelligence from analytical patterns.
